# SAT&gt;IP Freesat — Jellyfin Plugin Repository

Add this repository to Jellyfin to install or update the plugin directly from the catalogue.

**Repository URL:** `https://neilmanfredit.github.io/jellyfin-plugin-satip-freesat/manifest.json`

## How to add

1. Open Jellyfin **Dashboard → Plugins → Repositories**
2. Click **+** and paste the URL above
3. Go to **Catalogue**, search for *SAT>IP Freesat*, and install

## Jellyfin compatibility

| Plugin version | Jellyfin version | .NET target |
|---------------|-----------------|-------------|
| 2.x           | 12.x            | net10.0     |
| 1.x           | 10.11.x         | net9.0      |

Jellyfin will automatically install the version that matches your server.

## Requirements

- A SAT>IP-compliant DVB-S/S2 device on your local network
- Satellite dish pointed at Astra 2 at 28.2°E (standard UK Freesat/Sky dish)

See the [README](https://github.com/neilmanfredit/jellyfin-plugin-satip-freesat) for full setup instructions.
